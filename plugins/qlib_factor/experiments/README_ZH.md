# 当前实验指标

[English](README.md) · [简体中文](README_ZH.md)

- [factor_comparison.csv](factor_comparison.csv)：全部 16 个分组 × Top5/10/20/30，包含验证与样本外指标、风险、换手、成本及实际 Task / Run ID。
- [yearly_comparison.csv](yearly_comparison.csv)：各分组和 TopN 的分年指标。
- [selection_decision.json](selection_decision.json)：训练期验证选择规则与选中任务句柄。
- [baseline_data_parity.json](baseline_data_parity.json)：共享字段与完整预测的一致性核对。
- [context_feature_coverage.csv](context_feature_coverage.csv)：全部 26 个新增特征的覆盖率。
- [selected_feature_importance.csv](selected_feature_importance.csv)：选中模型的特征重要性。
- [training_parameters.json](training_parameters.json)：模型参数、标签、截止时间与选中轮数。

这些精简汇总随仓库提供。完整日级产物与模型保留在远程 Task 中，其他实验窗口见[历史归档](../archives/20261009/)。
