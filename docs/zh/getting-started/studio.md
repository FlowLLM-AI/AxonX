# Studio

从网站打开 Playground，可以在没有服务时查看虚构的 Task 记录、研究结果、工作区文件和脚本 Agent 会话。Playground 提供只读任务定义与记录，不再启动或取消 Task。刷新或重置示例可恢复初始模拟状态。

## 连接服务

安装 `axonx[studio]`，配置服务 token 后运行 `axonx start`。打开 `http://127.0.0.1:1024`，在 Studio 设置中填写连接 token。观察服务与独立 CLI 任务应共享 workspace 和日志路径。

所选机器决定任务列表、定义、日志、研究结果与工作区查询的 target。请求保留同源认证。Task 执行使用执行机器上的 CLI exec。

## 任务定义

任务定义页面按插件分组，支持搜索。选中任务后显示说明及输入输出 JSON Schema，不再提供执行表单或提交操作。

## 任务记录

全部任务页面按类型和注册名分组，支持搜索与类型、状态筛选，展开后每组显示 50 条。可以复制 ID 或打开详情，查看参数、关系、步骤、子任务与日志。列表和详情不提供 Task 取消、删除或多选操作。

Task 观察使用共享的 60 秒刷新调度，并保留手动刷新。切换机器或 Task 时取消过期请求。状态来自最后发布的 metadata；服务重启不会修复或终止独立的本地 exec 进程。

## 研究、文件与工具

研究页面读取成功任务的产物。策略比对在对齐的回测日期上计算指标，不启动新 Task。工作区浏览、预览与通用文件删除仍然保留；副本同步也独立于 Task 生命周期管理。

Agent 会话支持对话、会话管理和中断轮次。停止轮次不控制独立 Task。API 接口页面读取所选服务的 Job 目录；Task API 提供定义与观察查询。远程 CLI 仍是独立能力，其命令进程跟随该请求的生命周期。
